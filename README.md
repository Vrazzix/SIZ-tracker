# Детектор СИЗ на сотрудниках предприятия

## Описание
Система реального времени для детектирования касок и отслеживания сотрудников на производстве. 
Автоматически определяет нарушения техники безопасности и логирует инциденты.

## Быстрый старт

## Установка
```bash
git clone https://github.com/Vrazzix/SIZ-tracker.git
cd SIZ-tracker
pip install -r requirements.txt
```
